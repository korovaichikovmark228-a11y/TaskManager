Умный разбор на устройстве

Модель работает прямо в браузере, офлайн после первой загрузки. Бесплатно, данные не уходят с устройства. Нужен iOS 18+ (WebGPU). Первая загрузка ~0,6–1,2 ГБ, потом из кэша.

Умный разбор онлайн (облачная модель)

Работает при наличии интернета — понимает свободную речь по-настоящему. Бесплатно на бесплатных моделях. Получите ключ на openrouter.ai (без карты), вставьте ниже. Офлайн — автоматически разбор по правилам.

Умный разбор (Ollama, на своём сервере)

Необязательно. Точнее делит длинный ввод на задачи и определяет раздел/срок через локальную модель Ollama на вашем компьютере или сервере — бесплатно, без внешних API. Если модель недоступна, приложение автоматически использует разбор по правилам.

Синхронизация (Supabase)

Необязательно. Без этого приложение полностью работает офлайн на этом устройстве. Заполните, чтобы видеть задачи на всех устройствах.

# Задачи — личный офлайн-менеджер задач (PWA)

Персональное веб-приложение для быстрой фиксации задач голосом или текстом,
с автоматическим распределением по разделам, офлайн-режимом и режимом фокуса
(таймер + фоновая музыка). Один пользователь. Всё — open-source, без платных API.

## Возможности

- **Быстрый ввод** — текстом или голосом (Web Speech API, `ru-RU`).
- **Умный разбор** — один ввод режется на несколько задач, определяются раздел,
  срок («завтра», «к пятнице», «через 3 дня») и важность («срочно», «не горит»).
  Всё на правилах, без обращения к внешним сервисам (`js/parser.js`).
- **Экран подтверждения** — перед сохранением видно, как разложилось; можно поправить.
- **Разделы с приоритетом** — Работа → Свой проект → Сообщество → Отношения → Личное.
  Порядок и ключевые слова редактируются в настройках.
- **Офлайн** — всё хранится локально (IndexedDB) + Service Worker. Ставится на
  домашний экран iPhone как приложение.
- **Синхронизация (опционально)** — Supabase (почта+пароль), «последняя правка
  побеждает». Без неё приложение полностью работает офлайн на устройстве.
- **Режим фокуса** — таймер помодоро (25/5, настраивается) + процедурная фоновая
  музыка (lo-fi пэд, дождь, тёплый шум, бинауральные биения) — генерируется в
  браузере через Web Audio, без файлов и без лицензий.
- **Умный разбор (опционально)** — локальная LLM через Ollama (`js/llm.js`) точнее
  делит длинный ввод на задачи и определяет раздел/срок. Работает на вашем
  компьютере/сервере, бесплатно, без внешних API. При недоступности — тихий откат
  на разбор по правилам.

## Запуск локально

Приложению не нужен сборщик. Нужен любой статический сервер (Service Worker не
работает по `file://`):

```bash
npx serve .
# или
python -m http.server 8080
```

Открыть `http://localhost:8080`.

## Хостинг на GitHub Pages

1. Settings → Pages → Source: `main`, папка `/ (root)`.
2. Открыть выданный `https://<user>.github.io/TaskManager/`.
3. На iPhone: Safari → Поделиться → «На экран Домой».

## Синхронизация через Supabase (по желанию)

1. Создать бесплатный проект на [supabase.com](https://supabase.com).
2. В SQL Editor выполнить:

```sql
create table public.tasks (
  id uuid primary key,
  user_id uuid not null references auth.users(id) on delete cascade,
  text text,
  section_id text,
  priority text,
  due date,
  done boolean default false,
  deleted boolean default false,
  created_at timestamptz,
  updated_at timestamptz
);
alter table public.tasks enable row level security;
create policy "own tasks" on public.tasks
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
```

3. В приложении: ⚙ Настройки → Синхронизация → вставить Project URL и anon key →
   Готово → зарегистрироваться/войти. Разделы используют фиксированные id, поэтому
   на всех устройствах задачи ложатся в одни и те же разделы.

## Умный разбор через Ollama (по желанию)

По умолчанию ввод разбирается rule-based парсером (`js/parser.js`) — без сети.
Для более точного деления на задачи можно подключить локальную модель через
[Ollama](https://ollama.com):

1. Установить Ollama и загрузить модель:

```bash
ollama pull llama3.2      # или mistral, qwen2.5 и т.п.
```

2. Запустить сервер, разрешив обращение из браузера (CORS):

```bash
OLLAMA_ORIGINS='*' ollama serve
```

3. В приложении: ⚙ Настройки → «Умный разбор (локальная LLM)» → включить галочку,
   указать адрес (`http://localhost:11434`) и модель (`llama3.2`) → «Проверить связь».

Разбор происходит на вашем устройстве, данные никуда не уходят. Если модель
недоступна или ответила некорректно, приложение автоматически откатывается на
разбор по правилам — ничего не ломается. Даты в ответе модели дополнительно
проверяются детерминированным парсером (`js/parser.js`).

> ⚠️ Обращение к `http://localhost:11434` работает, когда приложение открыто
> локально (`http://localhost`). При хостинге по HTTPS (GitHub Pages) браузер
> заблокирует запрос к `http://` как «смешанное содержимое» — тогда используйте
> локальный запуск или разверните Ollama за HTTPS-прокси.

## Своя музыка (по желанию)

По умолчанию звук генерируется в браузере (файлы не нужны). Если хотите свои
треки — положите mp3 в папку `music/` и подключите их в `js/focus.js`.

## Структура

```
index.html            — оболочка
css/styles.css        — стили (тёмная тема, мобильная вёрстка)
js/db.js              — IndexedDB
js/parser.js          — rule-based разбор задач (RU)
js/llm.js             — умный разбор через локальную LLM (Ollama, опц.)
js/speech.js          — голосовой ввод
js/focus.js           — таймер + процедурная музыка
js/sync.js            — синхронизация Supabase (опционально)
js/app.js             — UI и логика
sw.js                 — Service Worker (офлайн)
manifest.webmanifest  — PWA-манифест
icons/                — иконки
tools/gen-icons.js    — генератор иконок (node tools/gen-icons.js)
tools/test-parser.js  — тесты парсера (node tools/test-parser.js)
```

## Тесты

Парсер (даты, важность, разделы, деление на задачи) покрыт тестами без
зависимостей:

```bash
node tools/test-parser.js
```
